# בדיקות

כל הבדיקות משתמשות **בנתונים בדיוניים בלבד**, ולא מתחברות לפרויקט Supabase אמיתי.

| פקודה | מה נבדק |
|---|---|
| `npm run test:db` | מבנה המסד וההרשאות (RLS): 94 בדיקות על PostgreSQL מקומי וזמני, כולל ניסיונות גישה לא מורשים |
| `npm run test:e2e` | רגרסיה של האפליקציה הקיימת: כל 14 המסכים, מנהלת וצוות, רוחב אייפון, מצב כהה, ומצב שבו הורדות חסומות |
| `npm test` | שתיהן |

דרישות: Node 22, PostgreSQL 15 ומעלה (ל-`test:db`), ודפדפן Chromium של Playwright (`npx playwright install chromium`).

## איך בדיקות הרגרסיה עובדות
- האפליקציה נטענת משרת מקומי קטן, כמו באחסון אמיתי.
- השעון נעול על **5/11/2026 09:30 שעון ישראל**, כך שנתוני ההדגמה זהים בכל הרצה.
- כל בדיקה פותחת דפדפן נקי, עם נתוני הדגמה חדשים.
- המספרים במסך מושווים לנתונים השמורים. דוח השכר מושווה גם לחישוב עצמאי בתוך הבדיקה.
- כל בדיקה נכשלת אם הופיעה שגיאה בקונסול או חלון דפדפן רגיל (alert/confirm).
