# מערכת CRM לניהול גן ילדים

אפליקציית דפדפן (HTML + JS, ללא שרת). לפתיחה: לפתוח את `gan-crm/index.html` בדפדפן.

## כניסה (נתוני הדגמה)
- מנהלת: קוד `1234`
- גננות וסייעות: קוד `1111`

את נתוני ההדגמה מוחקים במסך **הגדרות וגיבוי ← מחיקת כל הנתונים**. 4 הכיתות נשארות.

## מבנה הקוד
הקוד מחולק לקבצים קטנים בתיקיית `js/`. הם נטענים מ-`index.html` כסקריפטים רגילים, **בסדר קבוע**, וחולקים מרחב שמות אחד. כך אפשר להמשיך לפתוח את `index.html` ישירות מהמחשב, בלי שרת.

| תיקייה / קובץ | תוכן |
|---|---|
| `js/util.js` | עזרים: תאריכים, כסף, שעות, הגנה על טקסט (`esc`) |
| `js/ui/` | רכיבי ממשק, הודעות, חלון קופץ, אישור פעולה, הורדות |
| `js/data/` | נתוני הדגמה, שמירה וטעינה, משתמש מחובר, שאילתות |
| `js/views/` | קובץ לכל מסך (14 מסכים + כניסה וניווט) |
| `js/forms.js` | טפסים: ילד, עובדת, דוח יומי, תלונה |
| `js/actions.js` | כל הפעולות של הכפתורים |
| `js/main.js` | ציור המסך, האזנה לאירועים והפעלה. נטען אחרון |
| `tools/build-single-file.js` | בונה קובץ HTML אחד שכולל הכול (`node tools/build-single-file.js`), למשל לקישור באייפון |

**חשוב:** כל קובץ יכול להשתמש רק במה שהוגדר בקבצים שנטענו לפניו. בדיקה אוטומטית מוודאת שהסדר נכון.

## בדיקות
`npm test` מריץ את בדיקות ההרשאות של המסד ואת בדיקות הרגרסיה של כל המסכים. פירוט ב-`tests/README.md`.

## חשוב לדעת
- הנתונים נשמרים **בדפדפן של המכשיר שבו עובדים** (localStorage). כל הצוות צריך לעבוד על אותו מכשיר, למשל מחשב או טאבלט בגן.
  כדי שכל עובדת תעבוד מהטלפון שלה עם נתונים משותפים, צריך לחבר מסד נתונים בענן (למשל Firebase או Supabase).
- כדאי להוריד גיבוי באופן קבוע (מסך הגדרות).
- קודי הכניסה הם להפרדת הרשאות בסיסית בלבד. הם לא אבטחה אמיתית.
