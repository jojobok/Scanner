# 🎬 מחולל סרטוני פרשת השבוע (עד דקה וחצי) — בשיתוף Grok

התוכנה מזהה לבד את פרשת השבוע, שולחת לגרוק למצוא את **הנושא המרכזי**, מקבלת ממנו תסריט + פרומפטים לתמונות,
יוצרת תמונות, מקליטה קריינות בעברית ומרכיבה סרטון אנכי (9:16) של **עד 90 שניות** — מוכן לרילס/שורטס/טיקטוק.

## איך זה עובד

```
פרשת השבוע (Hebcal / חישוב מקומי)
      │
      ▼
גרוק ← שלב 1: מציע 3 נושאים מרכזיים ובוחר את החזק ביותר
      │
      ▼
גרוק ← שלב 2: תסריט 6–9 סצנות (קריינות + טקסט על המסך + פרומפט תמונה באנגלית)
      │            ↳ נשמר plan.json + prompts.md (אפשר לערוך!)
      ▼
גרוק Image ← תמונה לכל סצנה (בסגנון אחיד)
      │
      ▼
edge-tts ← קריינות בעברית (חינמי)
      │
      ▼
ffmpeg ← זום איטי על כל תמונה + כתוביות בעברית + מוזיקה → MP4 ≤ 90 שניות
```

## התקנה

1. Python 3.10+ ו-[ffmpeg](https://ffmpeg.org/download.html) מותקנים.
2. ```bash
   pip install -r requirements.txt
   cp .env.example .env      # ולהדביק את מפתח ה-API של xAI
   ```
   מפתח מקבלים ב-https://console.x.ai

## הרצה

```bash
# הכל אוטומטי - פרשת השבת הקרובה (לוח ארץ ישראל)
python -m parasha_video

# פרשה מסוימת
python -m parasha_video --parasha "וירא"

# עבודה "בשיתוף" עם גרוק: קודם רק תסריט, עוברים עליו, ואז ממשיכים
python -m parasha_video --stop-after script
#   ...עורכים את output/<תאריך>_<פרשה>/plan.json...
python -m parasha_video --from-plan output/2026-11-07_חיי_שרה/plan.json

# רוצים להחליף תמונה? שמים קובץ בשם scene_03.png (או jpg) בתיקיית images וממשיכים עם --from-plan

# לכפות נושא
python -m parasha_video --theme "הכנסת אורחים של אברהם"

# בדיקה בלי מפתח API (תמונות דמה)
python -m parasha_video --demo
```

### מה יוצא בתיקיית הפלט
| קובץ | מה זה |
|---|---|
| `פרשת_XXX.mp4` | הסרטון הסופי |
| `plan.json` | הנושאים שגרוק הציע, הנושא שנבחר, והתסריט המלא |
| `prompts.md` | כל הפרומפטים מסודרים — אפשר להדביק גם ידנית ב-Grok Imagine |
| `images/`, `audio/` | תמונות וקריינות לכל סצנה (נשמרות, כדי לא לשלם שוב בהרצה חוזרת) |

## התאמת הסגנון שלך 🎨

כל הסגנון מרוכז במקום אחד: מעתיקים את `style.example.json` ל-`style.json`, משנים ומריצים עם `--style style.json`.

- `visual_style` — תיאור הסגנון הוויזואלי (באנגלית) שמצורף לכל פרומפט תמונה. **כאן מתארים את הסגנון של הסרטון לדוגמה.**
- `tone` — טון הכתיבה של התסריט.
- `image_rules` — כללי רגישות (ברירת מחדל: לא מציירים את הקב"ה, דמויות מקראיות מאחור/בצללית בלבד).
- `tts_voice` — `he-IL-AvriNeural` (גבר) או `he-IL-HilaNeural` (אישה).
- `music_path` — קובץ מוזיקת רקע (MP3), `music_volume` — עוצמה.
- `font_name` — גופן לכתוביות. כדי להשתמש בגופן כמו Heebo / Rubik: שמים את קובץ ה-TTF בתיקייה `parasha_video/fonts/` ומעדכנים את השם.
- `watermark` — שם העמוד שיופיע בפינה.

## חשוב לפני פרסום ⚠️
גרוק מתבקש לצטט רק מקורות מדויקים, אבל **תמיד לבדוק את הפסוקים והמקורות** (מופיעים ב-`prompts.md`) לפני שמפרסמים.
